# 🇮🇳 Indian Flag — CSS Practice Project

A static Indian flag built using only **HTML** and **CSS**, created as a hands-on practice project while learning CSS fundamentals as part of my full stack web development journey.

## 🛠️ Tech Stack

- HTML5
- CSS3

## 🎯 Why I Built This

It is a deliberate practice exercise. While learning CSS, building something visual like a flag is a good way to apply positioning, sizing, and color concepts in a real layout.

## 📌 What I Practiced

- CSS selectors and combinators (`>`, type selectors)
- `position: absolute` and `position: relative` for layout
- CSS specificity and how conflicting rules are resolved
- Inheritance in CSS
- `border-radius` for circular shapes
- RGB color matching

## ⚠️ Known Limitations

| Issue | Detail |
|---|---|
| `<div2>` is invalid HTML | Used `<div2>` as a custom tag for the green stripe|
| Ashoka Chakra is incomplete | Only the outer ring and center dot are present — the 24 spokes are missing |
| Circle is slightly off-spec | The Chakra ring is 150×150px and not perfectly centered — correct size should be 200×200px |

## 📚 Part Of

This project is part of my full stack web development learning journey — rebuilding small UI components and layouts from scratch to reinforce core HTML and CSS concepts before moving to JavaScript and beyond.
